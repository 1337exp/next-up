# Дизайн Next Up

Сначала прочитай `docs/DESIGN.md`: там аудит, гипотезы и статус. Компоненты и токены — в скиллах `taoui` и `taoux`; не выдумывай свои, пока нужного нет в них.

## Принципы (по важности)

1. **Содержимое важнее служебного.** Текст заметки главный; срок, повтор, теги — уровнем ниже по размеру и контрасту. На строку не больше 2–3 служебных элементов.
2. **Частое — в один жест.** Создать, отметить выполненной, найти — без меню. Редкое (повтор, клон, корзина, настройки) — за одним касанием, не на первом экране.
3. **Ввод быстрее чтения.** От «+» до первого символа ни одного лишнего поля; дата по умолчанию «сегодня»; необязательное — под «Ещё».
4. **Телефон: основное внизу**, в зоне большого пальца. Цель касания не меньше 44 px. Размеры задаёт контекст (`tao-density-*`, `tao-size-*`), а не `size` на каждом контроле.
5. **Один главный элемент на экран**: одна кнопка `variant="primary"`, остальные `ghost` / `secondary`.
6. **Время словами, и сколько осталось:** в каждой строке (кроме группы «Сегодня») «через 3 дня» и дата под ним: пользователь не должен считать. Склонять через plural. Цвет никогда не единственный носитель смысла.
7. **Раскладка по ширине контейнера:** compact до 600, medium 600–839, expanded от 840 (как у `TaoNav`); без JS-ветвлений там, где хватит CSS. Широкие экраны: всё приложение ограничено 1320 px и стоит по центру, колонка текста в редакторе до 760 px (`docs/DESIGN.md`, §4). Название приложения в меню не показывать: мелкая строка внизу под «Настройками».
8. **У каждого экрана есть состояния:** пусто, загрузка, ошибка, «отменить». Не оставлять заглушку без смысла.

## Жёсткие правила реализации

- Цвета только ролями `--tao-color-*`; `#hex`, `rgb()`, `rgba()` в коде приложения запрещены. Отступы и шрифты — `--tao-space-*`, `--tao-font-size-*`.
- Свои токены допустимы только в `src/styles.css`, с префиксом `--nu-`, и когда роли TaoUI не хватает.
- Статус — `tone` + слово. Не переопределять внутренности TaoUI по классам `.tao-*__*`; не вводить свои множители размера.
- Тексты интерфейса: `src/i18n/ru.ts` и `src/i18n/en.ts` одновременно. Иконки — `tao-*` или `registerTaoIcons`.
- Ядро (`src/core`, `src/app`) ради дизайна не менять без явного решения; если нужно, сказать об этом отдельно.

## Проверка после правки интерфейса

1. `preview_start` с `dev`, скриншоты на **390, 768 и 1280** px в светлой и тёмной теме (`data-tao-mode` на `<html>`).
2. Клавиатура: `Tab`, `Enter`, `Esc`, видимый фокус; `/` ищет, `N` создаёт.
3. В консоли браузера нет ошибок.
4. `npm run typecheck` и `npm test` зелёные.
5. После проверки вернуть размер окна: `resize_window` с `preset: "desktop"`.
