# Next Up

Менеджер задач (список с датами, заметками в Markdown, чек-листами и повторами). Vue 3 + TypeScript + Vite + [TaoUi](https://www.npmjs.com/package/@1337exp/taoui).

План проекта: [docs/PLAN.md](docs/PLAN.md).

## Команды

```bash
npm install
npm run dev        # разработка
npm run build      # vue-tsc + vite build
npm test           # vitest
```

## Режим разработки

В настройках есть блок инструментов разработчика (пока там кнопка «Demo data», которая заменяет все задачи тестовыми). Обычным пользователям он не виден. Режим включается сам:

- при заходе по IP-адресу (`192.168.…`, `127.0.0.1`, `[::1]`) или на `localhost`;
- в сборке для разработки (`npm run dev`);
- принудительно флагом в `localStorage`: это позволяет отлаживать и рабочую сборку.

```js
localStorage.setItem('nextup-dev', '1');   // включить (в том числе на публичном домене)
localStorage.setItem('nextup-dev', '0');   // выключить (в том числе при заходе по IP)
localStorage.removeItem('nextup-dev');     // вернуть автоматику
```

Флаг проверяется при каждом открытии настроек, перезагружать страницу не нужно. Код инструментов лежит в `src/dev` и собирается в отдельный чанк, который загружается, только когда режим включён. Правила определения режима: `src/dev/mode.ts`.

## Шрифты и иконки

- Иконки: `src/assets/fontello` (набор fontello).
- Шрифт: замените заглушку `src/assets/font/roboto.css` на `@font-face` с локальными файлами Roboto.
