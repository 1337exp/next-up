# Next Up: дизайн

Рабочий документ редизайна. Ядро (`src/core`, `src/app`), тесты и синхронизация остаются; перестраиваем слой `src/ui/`, стили и тексты интерфейса.

Правила для работы лежат в проектном скилле [`.claude/skills/next-up-design`](../.claude/skills/next-up-design/SKILL.md), его читает Claude перед любой правкой интерфейса. Здесь — обоснование и статус.

## 1. Аудит текущего интерфейса

Интерфейс собран из компонентов TaoUI «как лежат», своего дизайн-языка нет (`src/styles.css` — 12 строк). Места и причины:

| Что | Где | Почему плохо |
|---|---|---|
| Шапка карточки: бейдж срока, бейдж дня недели, дата, значок повтора, меню — 4–5 элементов раньше текста заметки | `NoteCard.vue:106-124` | Главное (текст) стоит вторым. Дата и день недели разнесены на два элемента |
| Самое частое действие — «выполнено» — спрятано в меню «⋮» или в свайп | `NoteCard.vue:48-56, 64-73` | Два касания на ПК; на телефоне жест нельзя открыть, не зная о нём |
| Форма создания идёт в порядке модели данных: срок → чипы → панель Markdown → текст → пункты → повтор → «Готово» | `NoteEditor.vue:186-236` | Заметку начинают с текста, а не с даты. Панель Markdown съедает место над клавиатурой. Редкое (повтор) на том же уровне, что и главное |
| Пункты: корзина слева, перед полем, у каждой строки | `NoteEditor.vue:217-220` | Лишний тяжёлый элемент в каждой строке. Нет перестановки (в TaoUX 0.5 есть `sortable`) |
| Группировка активных по календарным месяцам с ярлыком «К4 / Октябрь» | `NoteList.vue:26-37` | Предстоящее мыслится как «сегодня / завтра / на неделе / позже». «К4» — жаргон |
| Пять равных пунктов навигации: Активные, Архив, Теги, Корзина, Настройки | `AppShell.vue:35-41` | На телефоне редкое (корзина, настройки) стоит наравне с основным; теги — фильтр, а не место |
| Пустая правая панель на ПК: «Выберите заметку» | `AppShell.vue:124` | Половина экрана пропадает |
| Все карточки одного веса, на каждой шум `surface="grain"` | `NoteCard.vue:104` | Нет иерархии: срочное и далёкое выглядят одинаково, кроме полоски |
| Подписи рельсы обрезаются на планшете («Активн…») | — | Видно на 768 px |

Сильное: адаптивность по ширине контейнера, отмена вместо подтверждений, автосохранение, цвет не единственный носитель смысла, ни одного hex в коде.

## 2. Практики, на которые опираемся

- **Иерархия** (гештальт, F-образное чтение): содержимое крупнее и контрастнее служебного; на строку не больше 2–3 служебных элементов.
- **Закон Фиттса и зона большого пальца**: на телефоне основное внизу; цель касания не меньше 44 px (Apple HIG 44 pt, Material 48 dp). У TaoUI это `tao-density-comfortable` / `auto`.
- **Закон Хика и постепенное раскрытие**: частое — на виду, редкое — за одним касанием.
- **Распознавание вместо припоминания**, видимость состояния, предотвращение ошибок (отмена вместо подтверждения уже есть).
- **Окна адаптивности Material 3**: compact до 600, medium 600–839, expanded от 840. Те же границы у `TaoNav` и контейнерных запросов TaoUI.
- **Скорость ввода**: от «+» до первого символа ни одного лишнего поля; дата по умолчанию «сегодня».
- **Система**: шаг 4/8 px (токены `--tao-space-*`), модульная шкала шрифта, не больше двух начертаний, контраст по WCAG 2 (в палитрах TaoUI проверен).

## 3. Гипотезы (проверяем на концептах, не решения)

- **H1 Время словами.** Активные группируются «Сегодня · Завтра · На этой неделе · Позже». Просроченных нет: по правилам приложения прошедший срок = архив.
- **H2 Строка вместо карточки.** Слева круг «выполнено», затем текст (1–2 строки), под ним одна служебная строка: срок словами · повтор · теги · «2/5». Тап открывает редактор.
- **H3 Быстрый ввод.** Поле «Что запомнить?» вместо формы: понимает «завтра», «в пятницу», «каждый понедельник», `#тег`. Полная форма — по «Подробнее».
- **H4 Редактор: сначала текст.** Затем срок одной строкой чипов; пункты; повтор и теги в «Ещё». Панель Markdown показывается только при фокусе в тексте.
- **H5 Навигация.** Основное: Скоро, Архив, Поиск. Теги — фильтры-чипы над списком. Корзина и настройки — в «Ещё».
- **H6 ПК: правая панель не пустая.** Когда ничего не открыто, там сводка на сегодня или месячный календарь (`TaoCalendar`).
- **H7 Свой визуальный язык.** Шкала типографики (заголовок раздела / текст заметки / служебное), меньше рамок, один акцент из палитр TaoUI, плоские строки без шума.

## 4. Решения (обсуждение 29.10.2026)

- **Быстрый ввод** («завтра позвонить маме», `#тег`, «каждый понедельник»): делаем. Разбор текста — новый модуль в `src/core` с тестами; поле постоянно в списке: внизу над навигацией на телефоне, сверху списка на ПК.
- **Раздел «Скоро»** вместо «Активные».
- **Дни до события видны в каждой строке** (кроме группы «Сегодня»): «через 3 дня» и под ним дата. Склонение: 1 день, 2–4 дня, 5 и больше дней, через plural в i18n. Это перенос из старого интерфейса (бейдж «Дней: N»), чтобы не считать в уме.
- **Название «Next Up» не занимает место в меню** (ведущим дела оно не нужно): мелкая строка «Next Up v3» внизу под «Настройками», как ссылка в подвале.
- **Широкие экраны** (холст A3, A4): предел ширины для всего приложения (1320 px: меню 240 + список 440 + колонка текста 640), а не только для текста (предложил пользователь: проще и предсказуемее, чем придумывать, чем занять место):
  - до 600 px: одна колонка, нижняя навигация, поле ввода над ней;
  - 600–839: рельса слева, список, редактор поверх списка;
  - 840–1199: рельса из иконок, список, редактор (предложение, пока не рисовано);
  - 1200–1599: как A3: боковая панель 240, список 440–520 (`TaoSplit`), редактор с колонкой до 760 по центру;
  - от 1320: всё приложение (меню, список, редактор) занимает 1320 px и стоит по центру, поля по бокам — фон страницы, как на A4 (там нарисовано 1680, по решению уменьшено до 1320). Колонка текста в редакторе до 760 по центру своей области.
- **Направление:** основа A. Календарь и недельная лента из B — по желанию позже (переключаемая панель, не привязанная к ширине экрана).
