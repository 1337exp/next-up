# Черновики issue для TaoUI и TaoUX, часть 2

Найдено на TaoUI 5.13.0 и TaoUX 0.5.4. Первый список (все пять пунктов закрыты): [library-issues.md](library-issues.md).

> **Статус: все три закрыты** в TaoUX 0.5.5 (`isolation: isolate` у строки, проп `tabbable`) и TaoUI 5.14.0 (`TaoList roving`). Обходы с `isolation` и ручным отключением Tab у кнопок свайпа убраны; свой roving-список в Next Up оставлен: у нас группы и свайп-строки, а не плоский `TaoList`.

## TaoUX

### 1. `TaoxSwipeRow`: лицевая панель перекрывает плавающий `TaoNav` (баг)

**Что.** У `.tx-swipe__front` стоит `position: relative; z-index: 1`, а у самого `.tx-swipe` нет своего контекста наложения. Поэтому панель каждой строки участвует в общем наложении страницы и рисуется **поверх** плавающей панели навигации (`TaoNav floating`, стеклянной): текст строк виден поверх подписей меню, а не под стеклом.

**Как воспроизвести.** Список строк `TaoxSwipeRow` на странице с `TaoNav :floating="true" surface="glass"` (ширина меньше 600 px), прокрутить так, чтобы строки оказались под панелью.

**Предложение.** `isolation: isolate` (или `z-index: 0`) на `.tx-swipe`, чтобы `z-index: 1` панели действовал только внутри строки.

**Обход в Next Up.** `isolation: isolate` на классе строки (`NoteRow.vue`).

### 2. `TaoxSwipeRow`: кнопки действий нельзя убрать из порядка Tab (улучшение)

**Что.** Скрытые кнопки действий остаются в порядке `Tab` (с 0.5.4 при фокусе они показываются). Для приложения со своим клавиатурным путём к тем же действиям (стрелки, пробел, Delete, клавиша меню) это четыре лишние остановки на строку; `disabled` отключает только жест.

**Предложение.** Проп вроде `tabbable: false` (или `keyboard: false`), который ставит `tabindex="-1"` на кнопки действий, оставляя их нажимаемыми.

**Обход.** После монтирования ставлю `tabindex="-1"` на все кнопки внутри строки (`NoteRow.vue`).

## TaoUI

### 3. Список со стрелочной навигацией (идея)

**Что.** Для списков записей (`TaoList`) полезен готовый «roving tabindex»: одна остановка `Tab` на весь список, стрелки ходят по строкам, `Home` / `End` в начало и конец. Сейчас это пришлось писать в приложении (`NoteList.vue`, около 25 строк).

**Предложение.** Режим `keyboard="roving"` у `TaoList` (или отдельный composable в TaoUX): выбранная строка с `tabindex=0`, остальные `-1`, обработка `focusin` и стрелок.
