## TaoUI

### 1. `TaoFileDrop`: файл, не подошедший под `accept`, молча пропадает (баг / улучшение)

**Что.** `TaoFileDrop` отфильтровывает выбранные или брошенные файлы по `accept` (`fileMatchesAccept`) и ничего не сообщает: нет ни события `change`, ни отдельного события об отказе. Пользователь выбирает файл, и «ничего не происходит». У нас так не импортировался старый файл `track.txt`: `accept=".json,application/json"`, а расширение `.txt`.

**Как воспроизвести.** `<TaoFileDrop accept=".json" @change="...">`, перетащить файл `a.txt`: `change` не приходит, подсказки об ошибке нет.

**Предложение.** Событие `reject(files, reason)` (или `invalid`) для файлов, отброшенных по `accept` и по размеру, и необязательная встроенная подпись об отказе. Тогда приложение может показать «Файл не подошёл» вместо тишины.

**Обход в Next Up.** Принимаем любой файл (`accept` не задан), а содержимое проверяет сам разбор с понятными ошибками (`src/ui/shell/DataSection.vue`).
