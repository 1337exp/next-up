# Черновики issue для TaoUI и TaoUX

Найдено при работе над Next Up на TaoUI 5.12.0 и TaoUX 0.5.2. Каждый пункт проверен в браузере; обходы в Next Up помечены. Уже исправленное (aria-label на обёртке, цвет `muted` в тёмной теме, `maxHeight` у `TaoTextarea`, подписи рельсы) сюда не входит.

## TaoUI

### 1. Скрытые поля `TaoSwitch` и `TaoFileDrop` растягивают документ (баг)

**Что.** Служебные `input` (`.tao-switch__input`, `.tao-sr-only` у `TaoFileDrop`) имеют `position: absolute`, но у переключателя и drop-зоны нет собственного `position: relative`. Ближайший позиционированный предок — окно, поэтому такие поля **не обрезаются** прокручиваемым родителем (`overflow: auto`) и растягивают документ.

**Как воспроизвести.** Страница на 100dvh с блоком `overflow: auto`, внутри которого длинная форма с несколькими `TaoSwitch` и `TaoFileDrop`. Прокручивается весь документ: `scrollHeight` 1433 при высоте окна 800; вне блока находятся ровно три таких поля (`bottom` 864, 1139, 1433).

**Ожидание.** Скрытые поля не влияют на размер документа.

**Предложение.** `position: relative` на корне `TaoSwitch`, `TaoCheckbox`, `TaoRadio`, `TaoFileDrop` (или `inset: 0` / `clip-path` у скрытого поля). Не проверяла `TaoCheckbox` и `TaoRadio`: возможно, у них то же.

**Обход в Next Up.** `position: relative` на прокручиваемых контейнерах (`AppShell.vue`).

### 2. Слот под меню в `TaoNav` (улучшение)

**Что.** Нет места для мелкой строки внизу меню под последним пунктом (версия, «о приложении», ссылка на репозиторий). Сейчас такую строку можно поставить только в содержимое страницы.

**Предложение.** Необязательный слот `#footer` в боковой панели и рельсе (скрыт в нижней панели).

**Обход.** Строка «Next Up v3» внизу страницы настроек.

## TaoUX

### 3. Live-область `useSortable` растягивает документ (баг)

**Что.** `useSortable` добавляет в конец `body` невидимый `div` с `aria-live` (`position: absolute; width: 1px`). Когда документ ровно по высоте окна, область оказывается на пиксель ниже, и страница получает прокрутку на 1 px (`scrollHeight` 801 при 800).

**Предложение.** `position: fixed` (например `top: 0; left: 0`) вместо `absolute`: область не зависит от высоты страницы.

**Обход.** `overflow: hidden` на `html` и `body` на широком экране (`styles.css`).

### 4. `TaoxSwipeRow`: публичный токен фона лицевой панели (улучшение)

**Что.** Лицевая панель красится в `var(--tao-color-surface-raised)` без возможности настроить. Если строка лежит прямо на фоне страницы (`--tao-color-bg`), панель светлее неё, и по углам виден «призрачный» край, особенно при своём скруглении строки. Радиус настраивается (`--tx-swipe-radius`), цвет нет.

**Предложение.** Токен `--tx-swipe-bg`, по умолчанию `var(--tao-color-surface-raised)`.

**Обход.** На строке локально переопределяю `--tao-color-surface-raised: var(--tao-color-bg)`. Побочно это меняет и подмешиваемый фон панелей действий.

### 5. `TaoxSwipeRow`: как проверять жест автоматически (вопрос)

**Что.** Попытка проверить жест из браузерной консоли синтетическими `PointerEvent` (`pointerType: 'touch'`) строку не сдвинула (`transform` остаётся прежним). Не понятно, дело в самой синтетике (`isTrusted`, `setPointerCapture`) или в подключении.

**Предложение.** Пример теста на реальных касаниях (Playwright, `page.touchscreen` или `CDP Input.dispatchTouchEvent`) в песочнице или в документации, чтобы приложения могли проверять свайпы так же.
